# Conformité légale (France / UE)

- Mentions légales sur tout site professionnel (LCEN art. 6) : identité ou raison sociale, SIREN/SIRET, adresse, contact, directeur de publication, hébergeur (nom, adresse, téléphone).
- Données personnelles (RGPD) : politique de confidentialité accessible depuis chaque formulaire, avec finalité, base légale, durée de conservation, destinataires, droits et contact.
- Formulaire : collecter le strict nécessaire. Case de consentement non pré-cochée si la base légale est le consentement.
- Traceurs : bannière seulement pour les traceurs non exemptés. Mesure d'audience exemptée (Matomo sans cookie configuré selon la CNIL) : pas de bannière, mais mention dans la politique.
- Accessibilité : déclaration d'accessibilité obligatoire pour le secteur public et, depuis le 28 juin 2025 (directive EAA), pour de nombreux services privés en ligne hors micro-entreprises. La publier dès qu'un site le demande, recommandée partout.
- Vente en ligne : CGV, prix TTC, droit de rétractation, médiateur de la consommation.
- Zéro fiction : aucun avis, client, logo, chiffre, certification ou visuel inventé. Une information absente masque la section.
- Procédure : skill `web-legal-fr`.
